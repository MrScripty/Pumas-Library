The normal launcher contains no canned inference output. Simulation is exclusively
under `test/`; screenshot runtime identity and response text explicitly label it.
Real HTTP transport to a fixture does not qualify inference, audio conversion,
provider cancellation, GPU memory, image quality or embedding quality.

The original empty-runtime observation and offline-build failure were superseded
by an explicitly authorized normal registry build. CMake was installed into an
isolated build virtualenv, and the repository's existing staging script fetched
the official pinned 8,123,282-byte ONNX Runtime archive. Archive and shared-library
hashes are recorded; the selected library was observed in the real process's
`/proc/PID/maps`. No native binary or dependency cache is committed.

The ONNX graph is generated by the existing
[`synthetic_onnx_fixture.py`](../../../scripts/release/synthetic_onnx_fixture.py).
Its 505 bytes encode real Cast/Add/Unsqueeze/Tile operations. The test sends real
requests and compares the result against the independently derived value
`1/sqrt(256) = 0.0625`; maximum absolute error was zero. No model weights were
downloaded, no paid inference occurred, and no user's machine was contacted.
Temporary runtime state was deleted after explicit unload and clean shutdown.

Pantograph's committed tiny BERT fixture was inspected at
`5cd834560333991827dd6406cf61ebf559bfc3eb`; it targets Pantograph's Candle adapter.
This Pumas gateway has no corresponding Candle provider. It was not falsely
presented as a Pumas BERT run, converted, or used to justify a new runtime backend.

Mixed-length batches remain a public runtime blocker. Source inspection suggests
a padding/postprocessing mismatch: `onnx_runtime/tensors.rs` pads inputs to the
batch's maximum token count, while `postprocess.rs::mean_pool` requires each
output token count to equal the original attention-mask length. That causal
explanation is an inference from source; the recorded external evidence is the
typed failure and runtime `Validation` log. No core fix was attempted.

Real execution now covers **single-input untrained ONNX embeddings**. Learned
model behavior, batches, chat, text, transcription, image generation and
image-to-text remain **unqualified**. Other adapters have deterministic simulated
coverage only. Audio generation, image editing, 3D and audio classification have
no executable reviewed playground adapter at this revision. The interface
reports each runtime's unavailable reason independently; the observed runtime
plugin inventory was empty, separate from its available built-in ONNX capability.

No unpublished bugfix was read or consumed. Adoption depends on the user's eventual
running Pumas build exposing compatible discovery and typed operations and reporting
its real readiness. Unpublished audio/model/runtime fixes may be necessary for their
models to become available or succeed; this prototype neither assumes those fixes
nor duplicates them. Refresh discovery and collect real receipts on that authorized
runtime once it is ready. A changed public DTO requires a focused adapter update and
contract evidence, not a backend rewrite.
