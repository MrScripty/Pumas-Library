# Generated Bindings

Local output and test area for the experimental host-language bindings. Only
this README, `support-matrix.json` and the C# smoke sources are tracked;
everything generated here is a build artifact and must not be hand-edited.

`support-matrix.json` is the machine-readable support decision: it currently
accepts no host tuple. See [Native bindings](../docs/native-bindings.md) for
the status, boundary, generation and check commands, runtime loading and the
evidence required before any tuple is admitted.
