# Pumas v0.8 release acceptance checklist

Package version remains **0.7.0**. The strict inference producer requires a
v0.8 source and reviewed target-specific runtime/schema inputs. Operation
contracts, byte custody, codec validation and local package checks establish
bounded results; they do not establish production inference acceptance.

This checklist complements the [distribution contract](headless-inference-distribution-v0.8.md),
[acquisition matrix](artifact-acquisition/reports/acceptance-matrix.md),
[runtime matrix](runtime-installations-and-model-adapters/reports/acceptance-matrix.md)
and [Image-to-Text contract](../contracts/image-to-text-v0.8.md).

Each receipt must identify the exact source or artifact hash, schema, runtime
and model bytes, selected profile/device and lifecycle scope. Borrowed owners
must survive consumer cleanup; owned children must settle and drain. Unknown
post-dispatch outcomes retain custody and must not be replayed.

## Archive byte limits

The inference producer checks the closed temporary archive against `MAX_PACKAGE`
(4 GiB) before exclusive publication. Payload totals alone cannot account for
framing, generated metadata and compression overhead. Oversize refusal removes
owned partials and produces neither final archive nor checksum. Regressions use
actual tar and ZIP writers with a scaled 1,024-byte budget for all three target
labels; positive round trips remain covered. These are format/admission checks,
not native target or inference qualification. Metadata limits, shared identity,
version gates and legal/runtime closure checks retain their existing scope.
