# Pumas v0.8 consumer contract assessment

This assessment uses published `72af693cf7fb9c644c1837aafc74d63bcf902cd9`, tree
`ea251167c6e45161ece814f673e2118cc3c4212d`. Product version remains 0.7.0.
The separate finite generic CLI reference extension changes only consumer
reference/tests and documentation; its native test executable is compiled from
that exact published backend. It does not relabel that executable as a new build.

## Smallest separate feature

The callable reference previously exposed JSON-RPC and descriptor selection but
left `/v1/capabilities` and `/v1/model-operations` transport to every caller.
Add `LocalHttpSession.capabilities(model, profile=...)` and
`model_operation(request)` using its existing selected owner and held retention.
This hides the repeated fence/framing/socket code while retaining the producer's
generic primitives, status, typed result and error/outcome fields. Native
pre-handler stale fencing returns an empty HTTP 412; the reference preserves it
as `body=None`, without manufacturing an operation envelope. It makes one
request, validates response correlation, has no elapsed model-response deadline
and refuses unsupported streaming locally. The server retains modality and
readiness decisions. The shared transport also preserves existing JSON-RPC
behavior; its existing process regression suite remains required.

The write set is `scripts/consumers/local_http_session.py`, its native process
tests, a separate controlled HTTP test file, the local HTTP reference contract
and this assessment. No acquisition S3/HF/importer, discovery restricted-profile
recovery, native runtime/provider, generated schema, release or binding generator
path changes. No new provider result, model identity, endpoint or ownership
protocol is introduced. Local test receipts distinguish actual missing-model
and stale-fence process results from controlled positive peer responses.

## Decisions that remain

A supported native binding needs one named consumer and its exact host language,
host runtime version, native OS/architecture, supported modality/error/async
contract and ownership/cancellation behavior, plus a real packaged host cohort.
The accepted matrix supplies no such tuple. Merely adding generic DTOs to a
generator cannot choose that support promise. This is a product/consumer decision,
separate from the implementable finite HTTP reference feature.

On-demand loading remains deferred by the unified gateway brief. Existing-model
reuse should first select an explicitly served/ready model and preserve its
runtime/profile/artifact identity. Broadening to unserved models needs an
explicit lifecycle/resource/duplicate-load/uncertain-outcome contract. Eidetic's
embedding-space identity and first supported host tuple also require explicit
acceptance; neither is safely inferred from names, dimensions or model labels.
